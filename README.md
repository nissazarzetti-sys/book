# Library OOP Mini

Project sederhana menggunakan PHP Object-Oriented Programming (OOP) untuk simulasi perpustakaan.

## Fitur

- Membuat object Book
- Membuat object Member
- Menampilkan informasi buku
- Menampilkan informasi member
- Membuat DigitalBook menggunakan inheritance
- Simulasi peminjaman buku

## Struktur Project

- Book.php
- Member.php
- DigitalBook.php
- index.php
- README.md
- .gitignore

## Cara Menjalankan

1. Simpan project di folder `htdocs`.
2. Jalankan Apache melalui XAMPP.
3. Buka browser.
4. Akses:

`http://localhost/library-oop-mini/`
